# Marcx Estillore — Software Engineer

I build and maintain secure, production-grade web applications that keep business operations running, with a focus on healthcare data, automation and legacy modernization.

## About

I'm a Software Engineer at a U.S.-based acute dialysis company, with 1+ year in the role. I work on a large, continuously evolving codebase made up of many connected modules and business workflows. I handle sensitive healthcare-related data, so security and HIPAA requirements are part of everyday engineering, not an afterthought.

## Experience

**Software Engineer** · U.S.-based acute dialysis company · 1+ year

**Product and platforms**
- Maintain a production-grade web application that supports core business operations and internal workflows.
- Designed and built a custom CRM platform tailored to the organization's operational needs.
- Implemented ticketing and issue management for internal workflows and requests.
- Developed a responsive maintenance calendar for scheduling, organizing and tracking maintenance activities.
- Built accounting and financial management applications.

**Security and compliance**
- Work with sensitive healthcare data while following HIPAA requirements and security best practices.
- Implemented Cloudflare security: DDoS protection, Web Application Firewall (WAF) and bot protection.

**Infrastructure and DevOps**
- Build and maintain Dockerized applications deployed on Railway.

**Automation**
- Built automated email notifications for operational workflows, including communications with supply vendors and stores.
- Create software and automation that reduce repetitive manual processes.

**Legacy modernization**
- Maintain, improve and extend legacy systems while preserving existing business logic.
- Refactor and add features in existing codebases without disrupting established workflows.
